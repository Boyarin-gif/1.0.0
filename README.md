# Plus Visuals 1.0.0 — исходный проект

Клиентский Fabric-мод для Minecraft 1.21.11 на Java 21. Этот проект продолжает приложенную пользователем базу Plus Visual 5.2.5; исходные функции и ресурсы сохранены, новые системы добавлены поверх существующей структуры.

## Требования сборки

- Java 21
- Gradle 9.2.0
- Minecraft 1.21.11
- Fabric Loader 0.20.1
- Fabric API 0.141.6+1.21.11
- Fabric Loom 1.14.10
- Совместимость с Sodium 0.8.15-beta.1+mc1.21.11 заявлена конфигурацией, но запуск с Sodium ещё не проверен.

В проекте нет Gradle Wrapper. Сборка выполняется командой `gradle build --no-daemon`; GitHub Actions workflow в `.github/workflows/build.yml` устанавливает Gradle 9.2.0 и выполняет эту команду.

## Изменения 1.0.0

- Добавлены входящие и исходящие заявки в друзья, раздельный список принятых друзей и индивидуальные настройки визуальных эффектов для каждого друга.
- Заявки передаются через существующий TCP-канал комнаты Plus Visuals. Это не глобальная социальная сеть: для доставки оба игрока должны находиться в одной комнате с поддерживающей протокол версией.
- Добавлены SHA-256 fingerprint файлов Plus Visuals и блокировка кооперативного чата/меток при несовпадении fingerprint.
- Добавлен приватный чат участников комнаты.
- Личные и общие метки хранятся раздельно; общие метки синхронизируются только при совместимой версии комнаты.
- Trails переведён на ограниченные цветные частицы за движущимся игроком; Jump Circles размещаются в горизонтальной плоскости у ног.
- В окне кастомизации добавлено масштабирование 3D-предпросмотра колёсиком мыши; вращение модели мышью сохранено.
- Главное меню оформлено в двухколоночном стиле Plus Visuals и дополнено кнопкой Discord.
- Бинды главного и кооперативного меню помещены в категорию Plus Visuals.
- Существующие Item Glow, HUD, настройки и аксессуары не заменялись заглушками.

## Известные ограничения

Это исходная dev-сборка, а не подтверждённый финальный релиз. Глобальная доставка заявок между любыми серверами/версиями требует отдельного общего сервиса, которого в проекте нет. Проверка fingerprint самоподтверждается клиентом и не защищает от подмены злоумышленным клиентом. При несовпадении fingerprint комната остаётся подключённой, но кооперативные функции блокируются — жёсткое отклонение соединения до подключения ещё не сделано. Визуальный нагрудник перекрашивает реальную часть надетой брони; отдельный слой торса при отсутствии нагрудника не реализован. Синхронизация надетой косметики и показ аксессуаров других игроков ещё не реализованы.
