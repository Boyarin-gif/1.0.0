Результат проверки Plus Visuals 1.0.0 (2026-11-03)

Статус: исходники подготовлены; сборка JAR в этой среде не выполнена.

Причины невозможности сборки:
- исполняемый файл `gradle` отсутствует;
- Gradle Wrapper и `gradle-wrapper.jar` отсутствуют в предоставленном архиве;
- локальные Gradle-кэши/дистрибутивы не обнаружены;
- сетевой DNS недоступен, поэтому загрузить Gradle и зависимости из Maven не удалось.

Проверено статически:
- JSON-синтаксис `fabric.mod.json`, `pvpplus.mixins.json`, `ru_ru.json` и `en_us.json` корректен;
- Java-исходники прошли синтаксический проход javac без обнаруженных ошибок разбора, но полный javac завершился ошибками отсутствующих Minecraft/Fabric классов — это НЕ компиляция проекта;
- конфигурация указывает Java 21, Minecraft 1.21.11, Loader 0.20.1, Fabric API 0.141.6+1.21.11 и Loom 1.14.10;
- `FriendArmorTintMixin` сохранён в конфигурации Mixin, но его загрузка в игре не проверена.

Не выполнено:
- `gradle build`;
- запуск Minecraft;
- проверка Sodium в реальном клиенте;
- двухклиентные тесты заявок, совместимости, чата, удаления друга и меток;
- измерение FPS;
- визуальная проверка всех моделей, интерфейсов и HUD.

Не создавался фиктивный JAR. После успешного GitHub Actions артефакт должен быть доступен как `plus-visual-1.0.0.jar` в `build/libs/`.
